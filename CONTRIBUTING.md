# Contributing

## How the repository works

`generator/icons/` is the only source. Each symbol is a Python function that returns stroke centre lines on a 24 × 24 grid, registered with `@icon(name, group, zh, replaces=…)`. `generator/build.py` turns those functions into every package:

| Output | Generated by |
| --- | --- |
| `svg/*.svg` | `gen_svg.py` |
| `android/yoin-symbols/src/main/res/drawable/ic_yoin_*.xml`, `YoinSymbols.kt`, `SymbolGeometry.kt` | `gen_android.py` |
| `web/dist/`, `web/svg/`, `web/font/`, `web/package.json` | `gen_web.py`, `gen_font.py` |
| `flutter/lib/yoin_symbols.dart`, `flutter/fonts/`, `flutter/pubspec.yaml` | `gen_flutter.py`, `gen_font.py` |
| `docs/index.html` | `gen_site.py` from `site_template.html` |

Never edit those files by hand; change the source and run the build. The hand-written parts are `android/yoin-symbols/src/main/kotlin/…/AnimatedSymbols.kt`, `SymbolMotion.kt`, `SymbolBuilder.kt`, the READMEs and the docs.

```sh
pip install -r generator/requirements.txt   # shapely, fonttools, brotli
python3 generator/build.py
```

Commit the source change and the regenerated files together. CI rebuilds everything and fails if the result differs from what is committed.

## Adding a symbol

1. Add a function to the right module in `generator/icons/` (`icons_nav.py`, `icons_music.py`, `icons_devices.py`, `icons_content.py`), using the helpers in `geom.py` and `knock.py`.
2. Follow the checklist at the end of [docs/DESIGN.md](docs/DESIGN.md).
3. Run the build and look at the symbol in `docs/index.html` at 1.25, 1.5 and 1.75, in light and dark.
4. Add a line to `CHANGELOG.md`.

The build appends the new symbol to `generator/codepoints.json`. Code points are permanent: never renumber or remove an entry, even for a deleted symbol, or icon fonts in existing apps will show the wrong glyphs.

## Changing a symbol

Refining a drawing is a patch release. Renaming or removing a symbol breaks every platform's API, so it waits for a minor release (while the version is 0.x) with a note in the changelog.

## Figma

The Figma file is maintained by hand from the same drawings. After a release that adds or changes symbols, import the new SVGs from `svg/` into the Symbols page, make them components with the same name and bind their strokes to `icon/default`.
